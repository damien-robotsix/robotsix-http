# Security Policy

## Supported Versions
Only the latest minor release line receives security fixes. This table is
updated at each release.

| Version | Supported |
| ------- | --------- |
| 0.9.x   | yes       |
| < 0.9   | no        |

## Reporting a Vulnerability
Please report security vulnerabilities privately. The preferred channel is a
GitHub private security advisory:
https://github.com/damien-robotsix/robotsix-http/security/advisories/new

You can also report by email to admin@robotsix.net.
Do not open a public issue for security problems.

## Response Time
This project is maintained by a single person and cannot guarantee a response
time. Reports are handled on a best-effort basis.

## Coordinated Disclosure
This project follows coordinated disclosure: please allow a reasonable window
to release a fix before any public disclosure.
