Add `stop_after_delay` wall-clock deadline to `RetryConfig`, bounding total retry loop runtime (including all attempts and sleeps). When set, the loop aborts before any sleep that would exceed the deadline, fires `on_retry_exhausted`, and re-raises the last exception — mirroring tenacity's `stop_after_delay`. Implemented in both `_retry_loop()` (retry.py) and `RetryClient.request()` (client.py).
